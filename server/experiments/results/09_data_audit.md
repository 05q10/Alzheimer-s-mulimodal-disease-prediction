## 2. TOTSCORE Identity

**TOTSCORE = ADAS11-Cog prorated subscale (0–70, higher = worse).**
Fractional values (e.g., 5.67) arise from prorating missing items:
`score = raw_sum / n_observed * 11`.
Verified by exact diff=0 against All_Subjects_ADAS_30Dec2025.csv on 4,850 overlapping (subject, visit) pairs.
Correlation with ADNIMERGE.ADAS11: r=0.9991. Correlation with ADNIMERGE.ADAS13: r=0.9805.
