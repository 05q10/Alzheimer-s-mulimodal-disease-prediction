## 5. Model Ablations

### A. Masked GRU vs Unmasked GRU vs GBM (MMSE@12m)

- **CatBoost GBM (Primary)**: Val MAE = **1.465**
- **Masked GRU (Values + Mask Channels)**: Val MAE = 1.525
- **Unmasked GRU (Imputed Values Only)**: Val MAE = 1.547
- *Finding*: Masking channels improved sequence learning over unmasked zeros, but GBM continues to outperform deep recurrent networks on this irregularly spaced cohort.

- MMSE@12m Without MRI: 1.465 MAE
- MMSE@12m With FreeSurfer MRI: 1.462 MAE
